
# Apresentação Projeto Tec+60: Conectando Gerações

O projeto **Tec+60: Conectando Gerações** tem como objetivo oferecer um curso de informática básica com acesso à internet para o público da terceira idade. Com a meta de atender 25 pessoas do município de Parnamirim, o projeto visa familiarizar os idosos com novas ferramentas tecnológicas.

O Tec+60 é um convite para que essa faixa etária se integre ao mundo digital, aprendendo a usar as tecnologias contemporâneas. A iniciativa demonstra que é possível aprender e se adaptar às novas demandas da sociedade moderna, promovendo um envelhecimento ativo e saudável.

Além disso, o projeto destaca a importância dos idosos na sociedade, contribuindo para sua inclusão e valorização no contexto atual.
